Puoi inserire qui i file MIDI (.mid) e gli Spartiti PDF (.pdf) da far scaricare dal sito.
Esempio:
- public/downloads/interstellar.mid
- public/downloads/interstellar.pdf

Nel pannello Admin (/admin), nei campi link basterà inserire:
- MIDI: /downloads/interstellar.mid
- Spartito: /downloads/interstellar.pdf

In alternativa puoi usare un link esterno diretto (Google Drive, Dropbox, Mediafire, GitHub, ecc.).
